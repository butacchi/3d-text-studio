# 3D Text Studio

3Dの文字アニメーションを作って、動画にして書き出せる、**無料**のツールです。
YouTubeチャンネル「ブタっち」で配布しています。インストールはいりません。

**最新版: v1.0.1**

## ダウンロード

**[最新版をダウンロード（Releases）](https://github.com/butacchi/3d-text-studio/releases/latest)**

1. ページの下のほうにある「Assets」から、`3DTextStudio_v1.0.1.zip` をダウンロードします。
2. zipを解凍します。
3. 中の `3DTextStudio_Butacchi_v1.0.1.exe` をダブルクリックします。

※ 解凍したフォルダごと、好きな場所に置いてください。EXEだけを別の場所に移すと、`fonts` フォルダを読めなくなります。

## できること

- 好きな文字を、3Dの文字にして動かす
- 見た目（エフェクト）を15種類から選ぶ
  ギンギラ(メタル) / ネオン輪郭 / 縁取り押し出し / ネオン発光 / ホログラム / 炎・ヒート / 電撃 / グリッチ / ゴールド / クローム / マット / ゴースト / レインボー / サイバー / ブラッド
- 色・線の太さ・光の強さを変える
- MP4 / WebM / PNG で書き出す（背景は緑・青・黒）
- 好きなフォント（.ttf / .otf）を追加する
- 設定を `.json` で保存・読み込みする

## 動作環境

- Windows 10 / 11（64bit）
- MP4の書き出しには、Windowsに入っているH.264エンコーダーを使います。

## Windowsの警告が出たとき

はじめて起動すると、「WindowsによってPCが保護されました」という画面が出ることがあります。
個人が作ったソフトでは、よく出る画面です。

→ 「**詳細情報**」をクリック →「**実行**」を押すと、起動できます。

ウイルス対策ソフトが反応する場合があります。**このページ（公式の配布場所）から入手したもの**か、確認してください。
ダウンロードしたファイルが正しいかは、Releases に載せている `SHA256SUMS.txt` のハッシュ値と比べて確かめられます。

## 更新のお知らせ

このソフトは、起動したときに、このリポジトリの `version.json` を読んで、新しいバージョンがあるかを確認します。
新しいバージョンがあると、画面の左下にお知らせが出ます。インターネットにつながっていないときは、何も出ません。
通信先はGitHubだけで、入力した文字や設定などは、送っていません。（通常のアクセスとして、GitHub側にIPアドレスなどは届きます。）
