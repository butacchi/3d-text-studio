# 3D Text Studio

3Dの文字アニメーションを作って、動画にして書き出せる、**無料**のツールです。
公式の配布場所は、**このGitHubのページだけ**です。インストールはいりません。

**最新版: v1.0.3**

**[使い方の解説動画（YouTube）](https://youtu.be/aT-1pzrFpfI)**

## ダウンロード

**[最新版をダウンロード（Releases）](https://github.com/butacchi/3d-text-studio/releases/latest)**

1. ページの下のほうにある「Assets」から、`3DTextStudio_v1.0.3.zip` をダウンロードします。
2. zipを解凍します。
3. 中の `3DTextStudio_Butacchi_v1.0.3.exe` をダブルクリックします。

※ 解凍したフォルダごと、好きな場所に置いてください。EXEだけを別の場所に移すと、`fonts` フォルダを読めなくなります。

## できること

- 好きな文字を、3Dの文字にして動かす
- 見た目（エフェクト）を15種類から選ぶ
  ギンギラ(メタル) / ネオン輪郭 / 縁取り押し出し / ネオン発光 / ホログラム / 炎・ヒート / 電撃 / グリッチ / ゴールド / クローム / マット / ゴースト / レインボー / サイバー / ブラッド
- 色・線の太さ・光の強さを変える
- MP4 / WebM / PNG で書き出す（背景は緑・青・黒）
- 好きなフォント（.ttf / .otf）を追加する
- 設定を `.json` で保存・読み込みする

## 動作環境

- **Windows 10 / 11（64bit）専用**です。Mac、Linux、スマホ、タブレットでは、動きません。
- WebGL2 に対応した、グラフィック機能（GPU）が必要です。ふつうのパソコンなら、問題ありません。
- 画面は、1280×720 以上をおすすめします。
- メモリは、起動した直後で約450MB使います。動かすと、もっと増えます。
- インターネットは、なくても使えます。更新のお知らせを出すときだけ、使います。
- 画面の言葉は、日本語だけです。

### 起動に時間がかかります

起動するたびに、約360MBを、パソコンの一時フォルダ（Temp）に取り出します。そのため、**画面が出るまで、10〜20秒ほどかかることがあります**（作者のパソコンでは、約9〜23秒でした）。
ソフトを閉じると、取り出したものは、自動で消えます。空き容量は、400MBくらい必要です。画面が出ないときは、そのまま待ってください。

### 動画の書き出し

- **MP4**は、Windowsの H.264 エンコーダーを使います。使えない環境では、画面に案内が出ます。その場合は、**WebM**で書き出してください。
- **WebM** と **PNG** は、ほとんどの環境で使えます。

### 動作を確認した環境

Windows 11 のパソコン1台だけです（AMD Radeon のグラフィック）。ほかの環境では、確認していません。
会社や学校のパソコンなど、ソフトの実行が制限されているところでは、動かないことがあります。

## Windowsの警告が出たとき

はじめて起動すると、「WindowsによってPCが保護されました」という画面が出ることがあります。
個人が作ったソフトでは、よく出る画面です。

→ 「**詳細情報**」をクリック →「**実行**」を押すと、起動できます。

ウイルス対策ソフトが反応する場合があります。**このページ（公式の配布場所）から入手したもの**か、確認してください。
ダウンロードしたファイルが正しいかは、Releases に載せている `SHA256SUMS.txt` のハッシュ値と比べて確かめられます。

## 更新のお知らせ

このソフトは、起動したときに、このリポジトリの `version.json` を読んで、新しいバージョンがあるかを確認します。
新しいバージョンがあると、画面の左下にお知らせが出ます。インターネットにつながっていないときは、何も出ません。
通信先はGitHubだけで、入力した文字や設定などは、送っていません。（通常のアクセスとして、GitHub側にIPアドレスなどは届きます。）
